# Resources & Further Reading

A curated collection of tools, tutorials, and references for the Game Design & Programming Club.

## GDevelop

- [GDevelop Official Site](https://gdevelop.io/) -- download or use the web version
- [GDevelop Wiki & Docs](https://wiki.gdevelop.io/) -- comprehensive documentation
- [GDevelop Education](https://gdevelop.io/education) -- educator pricing and resources
- [GDevelop YouTube Channel](https://www.youtube.com/c/GDevelopApp) -- official tutorials
- [GDevelop Community Forums](https://forum.gdevelop.io/) -- ask questions, share projects

## Free Game Assets

| Resource | What you get |
|---|---|
| [Kenney.nl](https://kenney.nl/assets) | High-quality free sprites, tiles, UI, and 3D models |
| [OpenGameArt.org](https://opengameart.org/) | Community-contributed game art (check licenses) |
| [Freesound.org](https://freesound.org/) | Free sound effects |
| [Free Music Archive](https://freemusicarchive.org/) | Free music (check licenses) |
| [Poly Haven](https://polyhaven.com/) | Free 3D models, textures, and HDRIs |
| [Sketchfab Free Models](https://sketchfab.com/features/free-3d-models) | Free 3D models in .glb format |

## Game Design Learning

| Resource | Type | Good for |
|---|---|---|
| [Game Maker's Toolkit (YouTube)](https://www.youtube.com/@GMTK) | Video essays | Understanding game design principles |
| [Extra Credits (YouTube)](https://www.youtube.com/@ExtraCredits) | Animated lessons | Game design, game industry, history |
| [The Level Design Book](https://book.leveldesignbook.com/) | Free online book | Level design theory and practice |
| [Game UI Database](https://www.gameuidatabase.com/) | Reference | HUD and menu design inspiration |

## Pixel Art Tools

| Tool | Cost | Notes |
|---|---|---|
| [Piskel](https://www.piskelapp.com/) | Free (web) | Great for beginners, animation support |
| [Aseprite](https://www.aseprite.org/) | $20 | Industry standard pixel art editor |
| [Lospec Palette List](https://lospec.com/palette-list) | Free | Curated color palettes for pixel art |

## Books (for curious students)

- [*The Art of Game Design*](https://schellgames.com/art-of-game-design) by Jesse Schell -- the definitive game design textbook
- [*Rules of Play*](https://mitpress.mit.edu/9780262240451/rules-of-play/) by Katie Salen & Eric Zimmerman -- game design fundamentals
- [*Level Up! The Guide to Great Video Game Design*](https://www.amazon.com/Level-Guide-Great-Video-Design/dp/1118877160) by Scott Rogers -- practical and fun
