# Maze Explorer — Wolfenstein Upgrade

Pink Horse Arcade FPS pass. Source of truth: this folder. Built output:
`site/static/arcade/games/maze-explorer/`.

## How to play

| Input | Action |
| --- | --- |
| **W / ↑** | Move forward |
| **S / ↓** | Move backward |
| **A / ←** | Turn left |
| **D / →** | Turn right |
| **Q / E** | Strafe left / right |
| **Space** or **Ctrl** | **FIRE** hitscan pistol |
| **Shift** | Sprint |
| **F** | Jump (optional) |
| **R** | Restart after death |
| Touch **FIRE** | Same as Space (Tesla / tablet) |

Win condition: **collect every gem**. Locked metal doors need a **key** (walk into the door while holding a key).

## Features

- **Combat**: 100 HP, 0.35s fire cooldown, hitscan cone ~800 units, muzzle flash + screen shake, red hurt vignette, death banner.
- **Enemies** (from `level.json` → `enemies[]`):
  - **Beholder** (boss) — slow float/bob, high HP, roar SFX, heavy melee
  - **Gargoyle** — medium chase/melee
  - **Pac-Man** — fast chaser
  - Patrol when idle; aggro + chase in radius; melee on contact
- **Level**: larger dungeon with **armory**, **tech wing** (servers), **crypt wing**, **treasure hall**, **secret alcove** (bonus gems behind a locked gate).
- **Pickups**: gems + keys (SFX). Doors delete when unlocked.
- **HUD** (DOM overlay): HP bar, READY/COOLING weapon, gems, keys, foe count, crosshair.
- **Audio**: gunshot, hit, death, hurt, pickups, door, beholder roar, ambient loop + mood theme (after splash).
- **Splash**: `/arcade/splashes/maze-explorer.png` via `splash.js`.
- **Touch / gamepad**: `ARCADE_CONTROLS` injected by `games/build-games.mjs` (big FIRE button).

## Level format additions

```jsonc
"enemies": [
  { "type": "beholder"|"gargoyle"|"pacman",
    "gx": 12.5, "gy": 15.5,
    "hp": 120, "speed": 45, "aggro": 700, "damage": 18,
    "meleeRange": 90, "float": true, "boss": true, "roar": true }
],
"doors": [
  { "id": "treasure-gate", "gx": 12.5, "gy": 12.95,
    "orientation": "ew"|"ns", "requiresKey": true }
]
```

Collectibles still use `{ "type": "gem"|"key", "gx", "gy" }`.

Combat lives in one large `BuiltinCommonInstructions::JsCode` block generated by
`generateCombatJs()` inside `compile-level.mjs`. SFX play via raw `Audio('./sfx/…')`.

## Rebuild

```bash
cd games
# Full 3D filter rebuild (runs minimap + compile-level + gdexport + shell inject)
node build-games.mjs --filter 3d

# Or just this game's compile step, then full export:
node 3d/maze-explorer/compile-level.mjs
node build-games.mjs --filter 3d
```

SFX source files live in `games/3d/maze-explorer/sfx/` and are copied into the
export as `site/static/arcade/games/maze-explorer/sfx/`.
